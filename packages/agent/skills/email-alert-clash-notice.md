# This one clashes

`clashes` is on the facts. Each entry is another commitment this occasion overlaps. The child cannot be at both. The entries are real; do not drop one and do not add one.

Write the one text you were already going to write, and say the clash in that same text: which commitment it overlaps, and when. Use only the title, child, when, ends, and location on each clash. Do not invent a drive, a reason, or a third plan.

This is still one message. Nothing is added before or after your words. If you cannot say the clash from those facts, return an empty `text`. Nothing else is sent in its place.
