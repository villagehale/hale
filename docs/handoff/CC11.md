# VIL-728: Groups: anti-bot-loop and rate guard so Hale never ping-pongs with another AI in a group
URL: https://linear.app/villagehale/issue/VIL-728/groups-anti-bot-loop-and-rate-guard-so-hale-never-ping-pongs-with

## Goal

If another AI (or a bot) is in the group, Hale and it never reply to each other in an endless loop.

## Scope

* Detect rapid back-and-forth patterns by **behavior in code** (turn rate, repeated replies to non-human senders, no human message in between), not by reading words.
* A per-chat rate guard: after N Hale messages with no human message in between, Hale goes quiet until a human speaks. N is a setting, not a user-visible phrase.
* When the guard trips, send nothing (do not announce it) and log an ops event; never send fixed copy.

## Acceptance criteria

* Simulated group with an echo bot: Hale stops after the cap; a human message resumes it.
* Normal multi-human groups are unaffected.
* Tests pass with the flag on and off; pin the clock.

## Rules that apply

No parent-visible copy added; no regex or word lists; Linq only. Full list: Linear document 'Claude Code handoff: Dec 1 launch'.
