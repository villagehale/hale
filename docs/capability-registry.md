Flag reads, as the code compares them:

- **`true`** means `=== 'true'` with no trim. `true\n`, `TRUE`, `on`, and `1` stay off.
- **`on`** means trim, then `=== 'on'`. `true`, `ON`, and `1` stay off.
- **trimmed `true`** means trim, then `=== 'true'`. `on` stays off. A trailing newline becomes `true`.
